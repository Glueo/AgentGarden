# 目的与边界

Agent Garden 服务于长期的人机协作：`garden/resources/` 归档外部材料的原始快照与全文译文，`garden/wiki/` 沉淀人和 Agent 都能阅读、链接与回滚的稳定知识、学习进度及导航，OpenViking 保存会话、记忆和 Garden 索引，Hermes 原生系统管理明确创建的 Skills。

系统优先保持简单。本阶段只有 Hermes、OpenViking、Obsidian 和 Git；不维护独立的经验晋升、Skill 蒸馏或验证服务。
