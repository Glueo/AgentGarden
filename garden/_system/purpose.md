# 目的与边界

Agent Garden 服务于长期的人机协作：保留原始轨迹，从重复实践中提炼经验，把稳定知识和可执行技能沉淀为人和 Agent 都能阅读、链接与回滚的资产。

系统优先保持简单。本阶段只有 Hermes、OpenViking、Obsidian、Dreamer 和 Git；不引入独立数据库、消息队列、额外 Wiki 服务或自动挑战模型。
