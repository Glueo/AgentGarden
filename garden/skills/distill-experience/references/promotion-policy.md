# Promotion policy

## Evidence

| Candidate | Minimum evidence | Destination |
| --- | --- | --- |
| Explicit personal preference | Direct user statement | OpenViking memory |
| Stable explicit knowledge | Attributable source and no unresolved conflict | Garden Wiki |
| Process lesson | One useful trace | Provisional OpenViking experience |
| Reusable process | Two independent successful traces | Experience candidate |
| Executable skill | Two independent successes plus isolated forward test | Garden skill |

Never use a model's numeric confidence as evidence. Prefer trace outcomes, user corrections, source quality, independent repetition, and forward-test results.

## Mandatory review

Always route credentials, security policy, deletion, payment, public publishing, external communication, medical, legal, and financial decisions to `garden/reviews/`. Also route unresolved contradictions and changes with unclear blast radius.

## Skill test record

Store source trajectory URIs, generalized behavior, representative and boundary inputs, isolated test command and exit code, observed filesystem/network effects, OpenViking snapshot, and Git commit in the Dream log.
