# 日语学习

目标：以《标准日本语》为主教材，建立可持续的日语学习节奏。日语当前属于长期兴趣线；算法与 Coding Agent Harness 项目仍是实习准备主线，负荷边界见 [[2026-2027 Agent实习准备计划]]。

## 当前基础

- 平假名可以闭卷写出。
- 首次随机认读测试共 20 个，正确 18 个，正确率 90%。
- 当前易错项：`ち = chi`、`ね = ne`。
- 片假名目前不能独立认读；采用随单词逐步熟悉的方式，不单独背诵片假名表。
- 历史笔记覆盖入门发音和第 1–7 课，但代表过去的学习进度，不等同于当前掌握程度。

## 执行规则

- 普通周安排约 2.5–3 小时，以 25 分钟短学习为主，不削减算法保底和项目最小推进。
- 从第 1 课开始诊断式复习：记得的内容快速通过，遗忘的内容按正常节奏重学。
- 每课按词汇与听音、语法、课文、练习与输出、复盘组成学习闭环。
- 片假名随词汇建立“字形—读音—词义”联系；只有反复混淆的字形才进入易错清单。
- 平假名只复习真实易错项，不重新抄写整张五十音图。
- 忙碌周只复习，不推进新课；未完成内容不在下一周加倍补债。
- 教材已有内容不重复抄录；每课只保留易错点和 5–8 个自己的例句。

## 五十音要点

### 标准行序

`a → k → s → t → n → h → m → y → r → w`

即：あ行、か行、さ行、た行、な行、は行、ま行、や行、ら行、わ行。

### や行与わ行空位

- や行只有 `や・ゆ・よ`，い段和え段为空位。
- 现代わ行只有 `わ・を`，中间为空位。
- `やいゆえよ`、`わいうえを` 可以作为记忆口诀，但用于占位的 `い・う・え` 仍属于あ行。

### 当前易错项

- `ち` 读作 **chi**；`さ` 读作 **sa**。
- `ね` 读作 **ne**。
- た行：`ta・chi・tsu・te・to`。
- な行：`na・ni・nu・ne・no`。
