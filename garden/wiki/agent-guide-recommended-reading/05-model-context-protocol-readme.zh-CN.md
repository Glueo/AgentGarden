# Model Context Protocol (MCP)

_刚刚听说 MCP，却不确定从哪里开始？请查看我们的[文档网站](https://modelcontextprotocol.io)。_

本仓库包含：

- MCP 规范
- MCP 协议模式
- MCP 官方文档

该模式首先[使用 TypeScript 定义](schema/2026-07-28/schema.ts)，同时也[提供 JSON Schema 版本](schema/2026-07-28/schema.json)，以实现更广泛的兼容性。

MCP 官方文档使用 Mintlify 构建，可在 [modelcontextprotocol.io](https://modelcontextprotocol.io) 查看。

Model Context Protocol 由 David Soria Parra（[@dsp](https://github.com/dsp)）和 Justin Spahr-Summers（[@jspahrsummers](https://github.com/jspahrsummers)）创建。
