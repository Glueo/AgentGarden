# Agent Garden 架构概览

Agent Garden 以 Hermes 作为交互与执行入口，以 OpenViking 保存会话、轨迹、记忆、经验与语义索引，以 Obsidian 保存人和 Agent 都能阅读的稳定知识与 Skill。

Dreamer 不因一次成功就固化过程经验。普通经验至少需要两个相互独立的成功轨迹；Skill 还需通过隔离前向测试。冲突、高风险或证据不足的候选进入人工审查。
